- `experience.html` — Experience

- `style.css` — Shared responsive design
- `script.js` — Mobile navigation and footer year

## Add your profile photo
Create an `assets` folder in the repository and upload your photo as `profile-photo.jpg`.
Then replace the photo placeholder in `index.html` with:
`<img src="assets/profile-photo.jpg" alt="Satya Prakash Rai">`

## Publish with GitHub Pages
1. Create a public repository, e.g. `satya-rai-portfolio`.
2. Upload all six files to the repository root.
3. Open Settings → Pages.
4. Select Deploy from a branch, branch `main`, folder `/ (root)`, then Save.
5. Site URL: `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`

Keep the HTML files, `style.css` and `script.js` in the repository root.
